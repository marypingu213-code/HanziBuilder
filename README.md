HanziBuilder
A web-based tool for turning Chinese characters into hands-on component puzzles, stickers, and worksheets. Designed for early childhood and special education, HanziBuilder helps children explore character structure through peeling, matching, layering, pasting, and writing.
HanziBuilder｜國字部件學習工具
將國字拆解成可操作的部件拼圖、貼紙與學習單，透過撕貼、配對、組合與書寫，幫助幼兒及特殊教育學生理解國字結構。
